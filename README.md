
# Login & Registration Project

A clean, responsive login and registration interface built with HTML, CSS, and JavaScript. This project demonstrates form validation, password visibility controls, and navigation between login and registration pages.

## Live Demo

Visit the live website: **[Open Login & Registration](https://YOUR-USERNAME.github.io/login-registration-project/)**

> Replace `YOUR-USERNAME` with your actual GitHub username.

## Features

- Responsive layout for desktop and mobile screens
- Login form with email and password validation
- Registration form with full name, email, and password fields
- Show and hide password controls
- Password confirmation validation
- Terms and Conditions checkbox
- Remember email option on the login page
- Navigation between login and registration pages
- Clear feedback messages for form validation

## Getting Started

To run this project on your computer:

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Use the links to navigate between the login and registration pages.

## Important Note

This is a frontend demonstration project. The forms perform client-side validation but do not create real accounts or authenticate users. Secure backend authentication is a possible future improvement.
